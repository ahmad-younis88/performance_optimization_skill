# 🚀 Universal Performance Optimization Skill

A language-agnostic, framework-free framework for diagnosing and fixing software performance issues across the entire stack.

## 🌟 Overview
This repository contains a comprehensive performance optimization strategy designed for modern software engineering. It moves beyond "tips and tricks" to provide a systematic **Diagnostic -> Isolate -> Verify** loop that can be applied to any project—from React frontends to Python backends and PostgreSQL databases.

## 🛠️ Key Components
- **Diagnostic Audit**: Measurement-first approach to baseline performance.
- **Critical Rendering Path**: High-impact frontend optimizations.
- **Logic & Computation**: Efficient execution and memory management.
- **Data & Backend**: Handling N+1 queries, indexing, and payload reduction.
- **Infrastructure**: CDN, compression, and networking best practices.

## 🚩 Critical Performance Killers
The skill focuses on identifying and fixing common "performance killers" including:
*   **N+1 Queries**: Batching and Eager Loading strategies.
*   **Layout Thrashing**: Efficient DOM manipulation.
*   **Memory Leaks**: Proper lifecycle management.
*   **Unindexed Scans**: Storage-level optimization.

## 📖 How to Use
1.  **Clone** this repository or copy the `SKILL.md` file into your project.
2.  **Follow the Checklist** provided in the `SKILL.md`.
3.  **Use the "Trace First" Rule**: Never optimize without a profiler trace.
